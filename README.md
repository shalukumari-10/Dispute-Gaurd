# Dispute-Gaurd

An AI-powered banking dispute management platform that helps users detect, track, and manage financial disputes through an intuitive dashboard.

## Features

- 📊 Interactive Banking Dashboard
- 💳 Transaction Monitoring
- 🚨 Fraud Detection Interface
- 📝 Complaint Management
- 🔒 Account Freeze Management
- 🔔 Notifications
- 📈 Analytics & Insights
- 🌙 Light/Dark Theme Support
- 📱 Responsive UI

## Tech Stack

- React
- TypeScript
- TanStack Start
- Vite
- Tailwind CSS
- shadcn/ui

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- Bun or npm

### Installation

Clone the repository:

```bash
git clone https://github.com/shalukumari-10/Dispute-Gaurd.git
```

Navigate to the project directory:

```bash
cd Dispute-Gaurd
```

Install dependencies:

Using Bun:

```bash
bun install
```

or using npm:

```bash
npm install
```

## Running the Development Server

Using Bun:

```bash
bun run dev
```

or using npm:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```

(or the URL shown in the terminal.)
